# Отчет по визуализации: Частота упоминаний и влияние легкости веса на рейтинг

## Тип визуализации
Столбчатая диаграмма с цветовой кодировкой по среднему рейтингу

## Описание
Частота упоминаний и влияние легкости веса на рейтинг

- **Тип диаграммы:** Столбчатая диаграмма с цветовой кодировкой по среднему рейтингу  
  **Обоснование:** Позволяет показать частоту упоминаний легкого веса и его влияние на оценки.  
- **Данные:**  
  - X: Упоминание веса (Легкий / Тяжелый / Не упоминается)  
  - Y: Количество упоминаний  
  - Цвет: Средний рейтинг (примерно 4.7 для легкого веса)  
  - Конкретные данные:  
    - Легкий вес: 25 упоминаний, 88% 5-звездочных, средний рейтинг 4.7  
- **Инсайты:**  
  - Легкий вес — значимый фактор удовлетворенности, особенно для женщин.  
- **Бизнес-польза:**  
  - Акцент на эргономике и облегчении труда в продукте и коммуникациях.
