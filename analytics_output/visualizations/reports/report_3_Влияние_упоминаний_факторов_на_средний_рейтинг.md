- **Обоснование выбора типа визуализации:**  
  Точечный график (scatter plot) выбран для наглядного отображения влияния каждого фактора на средний рейтинг. По оси X расположены категории факторов, по оси Y — средний рейтинг отзывов с упоминанием этих факторов. Размер точек отражает количество отзывов, что позволяет оценить значимость каждого фактора. Цвет точек дополнительно кодирует средний рейтинг, улучшая восприятие.
