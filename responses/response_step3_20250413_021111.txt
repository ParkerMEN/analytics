```python
import matplotlib.pyplot as plt

# Данные
labels = ['1/5', '2/5', '3/5', '4/5', '5/5']
sizes = [9, 6, 17, 0, 62]
colors = ['#ff9999','#66b3ff','#99ff99','#ffcc99','#c2c2f0']
explode = (0.1, 0, 0, 0, 0)  # выделение первого сегмента

# Построение круговой диаграммы
plt.figure(figsize=(8, 8))
plt.pie(sizes, explode=explode, labels=labels, colors=colors, autopct='%1.1f%%', startangle=140)
plt.title('Распределение отзывов по оценкам')
plt.axis('equal')  # чтобы круг оставался кругом
plt.show()
```

Круговая диаграмма, визуализирующая распределение отзывов по оценкам:

- Большая доля (≈ 65.9%) отзывов с оценкой 5/5 выделяет значительное доминирование положительных отзывов.
- Небольшая доля негативных отзывов (1/5 и 2/5) позволяет быстро оценить уровень неудовлетворенности среди клиентов.
- Отсутствие отзывов с оценкой 4/5 может указывать на резкое разделение мнений: клиенты либо очень довольны, либо нет.
