# MarketAnalytics - Аналитика продаж на маркетплейсах

Адаптивная веб-страница для визуализации аналитических данных по продажам на маркетплейсах.

## Технологии

- HTML5 / CSS3
- JavaScript
- Bootstrap 5
- Plotly.js для интерактивных графиков

## Установка и запуск

1. Скачайте или клонируйте репозиторий
2. Откройте файл index.html в браузере
